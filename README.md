# natickOS SuperNOVA

natickOS is an ongoing research project about how Linux distributions work and what it takes to make a successful one. 

## Dependencies

### Ubuntu 26.04
`sudo apt install build-essential clang lld llvm cmake ninja-build git curl xz-utils python3 pkg-config`
